# THREAD icon set — 59 source SVGs

Every icon is a custom-authored **24×24 SVG** with consistent `1.7` stroke weight, rounded line caps and simple geometry. Use a 20 px display size for desktop controls, 16 px for compact actions and 24 px for navigation. Icons use `currentColor` to inherit semantic tokens. Risk must never be communicated through an icon alone.

See [brand and icon rules](../../guides/02_BRAND_AND_ICONS.md) and [accessibility](../../guides/07_ACCESSIBILITY.md). This proposed library is not yet integrated into the React application; its existing icons live in `app/src/components.tsx`.
