# THREAD Design System / Source and status

This directory contains the published interactive design system, color tokens, four brand SVGs and 59 source vector icons.

[Open the visual reference](../index.html) and read [the design system README](../README.md).

**Status:** design system v1 is a proposal derived from the current THREAD prototype. The running planning application is unchanged. Dark theme and proposed components are not yet implemented in the production demo.

For the complete component specifications, accessibility rules, motion principles and QML migration notes, use the complete design-system ZIP delivered with the project.
