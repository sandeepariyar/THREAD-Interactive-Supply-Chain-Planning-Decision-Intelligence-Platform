# UX writing and truthfulness

The operator voice is precise, calm and explanatory. Always identify scope: SKU, warehouse, factory, store, draft, baseline, last run, projection and unavailable. Do not claim AI, real-time systems or optimization performance without evidence.

## Content rules
| Avoid | Prefer |
| --- | --- |
| Engine online / convergence | Illustrative local model |
| Apply to Live Plan | Save scenario draft |
| Execute rebalance | Stage rebalancing option |
| 43 impacted products for a pre-existing flag | 43 catalog SKUs flagged for review |
| Stock 900 | Available stock: 900 units at DC East for SKU … |
| +14% for rate 69% → 83% | +14 percentage points |
| Results after draft edit | Last simulated results; draft changed |
| Network risk high | DC East projected below safety stock in Week 5 |

## Structured alerts
[Entity] is [state] [when] because [cause]; [optional next investigation].

Example: DC East is projected below the two-week safety buffer in Week 5 because promotional demand exceeds scheduled replenishment. Inspect alternatives.

## Empty, error and offline
- No matching products. Clear filters or search another SKU.
- Changes have not been simulated. Run to update projections.
- Projection unavailable for this SKU. Baseline data is incomplete.
- Simulation could not complete. Your draft is unchanged.
- Draft saved in this browser. No operational systems were changed.

Use explicit dates, time zones where relevant, and measurement units. Financial values are illustrative assumptions, never accounting-grade outputs.
