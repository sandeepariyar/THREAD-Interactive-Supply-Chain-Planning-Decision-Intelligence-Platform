03 / Behavioral patterns

From observation to decision.

Each stage clarifies what the user is seeing, what they can change, and whether data is observed, inferred or simulated.

BEHAVIOR / 03
01 / DISCOVER

Find the product.

Show 1,284 catalog items, filtered results, and the selected SKU. The journey starts with an entity, not a KPI.

Explore → Select
02 / EXPLAIN

Follow dependencies.

Focused nodes connect retail, DCs and factories. The selected path persists as details emerge.

Select → Inspect
03 / SIMULATE

Evaluate the consequence.

Draft assumptions remain distinct from the last run. Compare time-based projections and stage alternatives.

Edit → Run → Compare

06 / Implementation handoff

Same language. Different renderer.

React and Qt/QML can share the same tokens, assets, naming, states and behavior—without pretending the code is mechanically convertible.
